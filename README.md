# Blacksite Relay

A desktop browser first-person combat sandbox built with Three.js and TypeScript.

## Play locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, click **Enter Simulation**, and use:

- `WASD` — move
- Mouse — aim
- Left mouse button — automatic fire
- `Space` — jump
- `R` — reload
- `Escape` — release the cursor

## Verify

```bash
npm test
npm run build
```
